拾词 WordNest 0.4.2 · Windows 64 位便携版

启动
1. 完整解压 WordNest-0.4.2-Windows-x64.zip，打开其中的 WordNest 文件夹。
2. 双击 WordNest.exe；无需安装 Java、配置 API 或联网。
3. 等待资料加载完成，输入英文单词并按 Enter；Ctrl+L 可聚焦搜索框。
请保留整个文件夹，app、runtime、文档和许可证需要一起保留，不能只取出 EXE。

本次更新
- 例句优先显示双语卡片：英文在上、中文在下，查询拼写或来源明确记录的词形会高亮。默认显示前 3 条，点击“展开其余”继续看。
- 每句的作者、编号、许可和链接放在自己的“出处”里，点击展开或收起；来源地址可选中复制，不会自动打开浏览器。
- 有双语例句时，“英文例句”默认收起。没有直接使用查询拼写的 WordNet 原句放在“补充英文例句”中，可能使用词形变化或同义词，原资料未提供中文译文。
- 常用搭配、词源原始记录和参考来源按需展开；各分页、各分组独立记住展开状态，切换单词后恢复默认。
- 新增系统托盘与窗口后台设置。点击关闭按钮不再固定等于退出，具体操作见下方。

查词与复习
- 顶部可切换“置顶”和“复制查词”。复制查词只接受英文字母组成的单词；中文、句子、图片等不会替换当前词。
- 四个分页是“例句、派生、词根、近义词”。主词库收录的相关词可点击继续查询。
- 原创例句标明“非考试真题”；社区译文保留简繁体。WordNet 英文例句不自动补译，义项和来源保留供核对。
- 派生、词基、复合词和复数/过去式有区别；词根说明区分历史来源、现代构词和助记。
- 近义词不能在所有句子中互换。可展开“参考来源”或“开放资料出处”查看地址，不会自动打开浏览器。
- “我的例句”停止输入约 750 毫秒后保存，非空笔记自动收藏；切换分页保留编辑内容。
- 生词本支持搜索、翻卡和 CSV 导出；再次点击“已收藏”会删除该收藏及个人例句。
- 中文释义按词性分行，浅绿色突出首条；“英文释义 ＋”默认收起，点击查看完整内容，切换单词后重新收起。

关闭、最小化和后台运行
1. 点击关闭按钮 × 或按 Alt+F4，默认询问“最小化到系统托盘”“退出程序”或“取消”。勾选“记住我的选择”后，下次会按该选择处理。
2. 顶部“设置”可分别修改关闭与最小化方式，也可把关闭方式改回“每次询问”。最小化按钮 − 默认缩到任务栏，可在设置中改为托盘。
3. 藏到托盘后，复制查词仍按开关状态运行，但不会自动弹出窗口。图标可能收在任务栏右下角的小箭头中。
4. 双击托盘拾词图标，或右键选择“显示拾词”，即可恢复窗口；再次打开 WordNest.exe 也会请求唤回已运行的窗口。
5. 右键托盘图标可开关“复制查词”、进入“窗口与后台设置…”或选择“退出拾词”。“退出拾词”会完全退出，不受记住的关闭方式影响。
托盘不可用、添加图标失败或保存失败时，程序会保留或恢复窗口并提示。若提示笔记尚未保存，请先处理保存问题。

资料与边界
770,611 是主词库记录数，不表示每个词都有完整中文学习卡。
WordNet 覆盖 127,311 个词头；词源数据为 2023-12 快照，覆盖 134,158 个词头。
0.4.2 沿用已有学习资料，未扩充词库。7,684 个优先词中，6,260 词有双语例句、5,416 词有词族/派生记录、6,887 词有词源记录、6,510 词有近义关系；4,078 词四栏都有资料。
优先词中有 4,948 词带 ECDICT 的 ielts 标签，这不是雅思官方完整词表。原有 355 张完整中文学习卡保留；精确统计见 LEARNING_COVERAGE.md，逐词表见 learning-coverage.tsv。
资料之间会重叠，不能相加。自动提取的词源可能有疏漏，中文整理也不等于专业词典编辑逐条审定。
缺少学习资料时如实提示；本版没有联网查询、发音、OCR、整句翻译、运行时 AI、云同步或 CSV 导入。

个人数据与升级
收藏、个人例句和设置保存在 %LOCALAPPDATA%\WordNest，在资源管理器地址栏输入即可打开。
升级前先完全退出旧版：若在托盘中运行，右键拾词图标选择“退出拾词”。仅隐藏窗口不等于退出。
退出后复制整个数据目录作为备份，再把新 ZIP 完整解压到新目录；保留旧包，不向旧目录零散覆盖文件。
同一 Windows 用户下的新旧版本共用该数据目录。启动时如果提示旧版仍在运行，先退出旧版再启动新版。

验证与源码
本版实际检查结果见 VALIDATION.md；验证范围为 Java 17 无窗口逻辑、真实 Swing 控件离屏布局与 EXE 资源自检。
未在真实桌面进行系统托盘、关闭、最小化、唤回、焦点或系统 DPI 交互验收，也未读取真实剪贴板。
源码版需 JDK 17+：先运行 scripts\build.ps1，再用 Launch.cmd 启动；源码或资源更新后要重新构建。
新增资料可用 python scripts\prepare_open_learning.py --check 离线核对。
中文卡的编辑源在 data\learning；运行 python scripts\assemble_curated.py 可重新合并，附加 --check 只检查结果。
完整构建、操作与边界见 README.md，来源许可见 THIRD_PARTY_NOTICES.md、licenses 和 runtime\legal。

下载页还提供源码 ZIP、SHA-256 校验和与单独使用说明。标题栏与正文保持浅绿白与深绿色，不改变 Windows 主题；请保留 app/lib 中的界面依赖文件。
