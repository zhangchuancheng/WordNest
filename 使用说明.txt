词巢 0.7.5 · Windows 64 位便携版

启动
1. 从 https://github.com/zhangchuancheng/WordNest/releases/tag/v0.7.5 下载 词巢-0.7.5-Windows-x64.zip，完整解压后打开其中的“词巢”文件夹。
2. 双击 词巢.exe；无需安装 Java、配置 API 或联网。
3. 首次启动会从随包资源建立词库缓存，请等待加载完成，再输入英文单词或简短词组并按 Enter；Ctrl+L 可聚焦搜索框。后续启动复用缓存，过程不需要联网。
请保留整个文件夹，app、runtime、文档和许可证需要一起保留，不能只取出 EXE。

本次更新
- 已核对的推荐双语例句会在英文原句前显示“本句用法”，说明目标词在该句中的词性与中文译法。首批为 release 的三条例句；其他句子尚未逐条核对，不自动猜测。
- 更名为“词巢”，窗口、托盘、桌面快捷方式及程序文件使用新名称；图标采用选定的橙底绿色词巢与 A 字母卡。个人数据目录沿用 WordNest，旧资料自动保留。
- 主词库扩充为 3,403,176 条：原有 770,611 条完整保留，遇到同名词头仍优先使用原库，另补入 2,632,565 条历史数据中的词条。
- 支持复制简短词组、输入格式整理和基于词库显式关系的词形候选；不靠截词尾猜原形。
- 新增条目显示“来源：ECDICT 扩充词库”。来源包含历史社区与网络释义，可能混杂或过时，未逐条专业审定；仍不覆盖所有新词。
- 保留 10 / 20 词计划复习、本机英文朗读、查词历史、取消收藏恢复与例句整理，不加入自动翻译或 AI。复习仍存 review.tsv，收藏仍为 v2 格式。
- 首次启动在 dictionary-cache 建立可重建的词库缓存，不把个人笔记或复习进度放入缓存。从 0.4.x 升级仍需注意旧生词本迁移，请先阅读“个人数据、升级与回退”。

计划复习
1. 打开“生词本 → 计划复习”，选择“10 词一轮”或“20 词一轮”，点“开始复习”。若上轮尚未完成，点“继续本轮”接着已保存的一轮，此时不会按新数量重开。
2. 先回忆词义，点击“显示释义”核对，再按自己的掌握情况点“忘记”或“记住”。每次回答后保存当前位置和下次复习时间。
3. 完成后显示“本轮完成”，汇总记住、忘记及取消收藏跳过的数量。可在有到期词或新词时点“开始下一轮”，不会无限循环。
4. 关闭复习窗口或退出程序后，再打开点“继续本轮”。尚未评分的当前题仍需重新点“显示释义”；已评分进度保留。“查看生词本”可返回收藏，“刷新计划”更新可复习数量。

先复习已到期的当前收藏，再加入从未复习的新词；不足 10 / 20 词时按实际可用数量开始，不用未到期词凑满。已取消收藏的词会跳过，不计为答对或答错。
连续选择“记住”后，间隔依次为 1、3、7、14、30、60 天，最后保持 60 天；选择“忘记”会重置档位，10 分钟后再次到期。不会在同一轮中重复插入忘记的词，也不会弹出系统提醒。
这是明确的固定间隔安排，不是 Anki 或 FSRS 算法，不预测个人记忆效果。
review.tsv 损坏或无法读取时，原文件保留并提示计划复习不可用，查词和生词本仍可用；回答保存失败时不跳到下一题，请处理提示后重试。

英文朗读
1. 在查词页搜索框下方选“语音”，调节“语速”；范围 -3 到 3，0 为正常，负值较慢，正值较快。选择保存在 settings.properties 中。
2. 点击单词或例句旁的朗读按钮；计划复习中的“朗读单词”可读当前题，编辑区可点“朗读我的例句”。个人例句按输入内容朗读，不先翻译；建议填写英文，混入中文不保证读音合适。单次最多 4,000 字符，超过时提示，不自动截断。
3. 可点击“停止朗读”；切换词条或退出程序也会停止。

朗读使用本机已安装、可被 Windows System.Speech 发现的英文桌面语音，不上传文字、不联网请求，也不会自动下载语音。Windows 设置中的自然语音或其他应用语音不一定可用于这里。
没有可用英文语音时会友好提示，其他查词与复习功能仍可使用。合成读音不是词典录音，实际声音和口音取决于所选语音。
自行添加系统语音可参考微软说明；是否能用于词巢，仍以应用语音列表为准：
https://support.microsoft.com/en-gb/education/learning-accelerators/download-languages-and-voices-for-immersive-reader-read-mode-and-read-aloud

查词与历史
- 顶部可切换“置顶”和“复制查词”。复制查词接受原文本最多 120 字符、整理后最多 8 个英文词，支持词内撇号和连字符，例如 can't、well-being。会整理全角英文、弯引号、Unicode 连字符、多余空格、NBSP 与制表符，并去掉首尾引号和常见句读标点。
- 多行、过长内容、中文、数字、图片、URL、邮箱及常见代码符号不触发复制查询。这不是语义整句判别：8 词以内的纯英文短句可能通过过滤，但应用仍只查已收录词条，不做整句翻译。手动查询也有 120 字符上限，可精确查询词库收录的 C++ 等特殊词头。
- 先查原输入，未命中再整理格式，例如 can’t → can't、well‑being → well-being；两者均未命中时，才尝试词库明确记录的词形关系。唯一有效原形自动打开，底部提示“按原形「…」查询”，例如 takes a back seat → take a back seat。took into account 本身已收录，会优先直接命中。
- 多个有效原形会显示“有多个可能原形，请手动选择。”。在“请选择原形…”中选中后点“查看”，或点“收起”；选择前保留当前词条、笔记与历史。候选较多时也需要手选或缩短查询，不按上下文猜选。若提示词形索引不可用，精确查词和格式整理仍可使用。
- 自动复制未命中时保留当前词条；手动未命中时，在当前笔记保存成功后显示“没有找到这个词或短语”。启动或重新开启复制查词不会立即查询剪贴板里的旧内容；检测间隔约 650 毫秒。
- 点击“← 后退”“前进 →”，或在应用窗口内按 Alt+← / Alt+→，回看本次打开程序后的查词路径。
- 点“历史”，选中词条后点“查看词条”重新打开。最近列表按新查询排序，忽略大小写去重；重查已有词会移到最前，未找到的词不记录。
- 启动显示上次词条不计为新查询；前进后退不改变最近列表顺序。回退后查询另一个词会结束原来的前进路径，连续查当前词不增加重复导航步骤。
- “历史 → 清空历史”确认后清除最近列表和本次前进后退路径；当前词条、收藏和个人例句保留。
- 历史文件损坏或无法读取时，原文件保留，本次历史改为只在内存中保存，查词和生词本仍可使用。若运行中历史写入失败，会提示未能保存，但本次仍可前进后退。

收藏、个人例句与导出
- 点“收藏”加入生词本。再次点“已收藏”只取消收藏，个人例句仍在本机；窗口底部“撤销取消收藏”可恢复刚取消的一项。
- 打开“生词本 → 最近取消收藏”，选中条目后可点“恢复收藏”，也可点“查看词条”继续编辑笔记。重启后仍能从这里找到保留条目。
- “我的例句”停止输入约 750 毫秒后保存。第一次填写非空笔记会自动收藏；已取消收藏的词继续编辑只保存笔记，不会自动重新收藏。
- 切换学习分页保留编辑内容。个人例句最多 20,000 字符；切词或退出前会尝试保存，失败时保留当前内容并提示，请先处理保存问题。
- 生词本可搜索当前收藏的单词、中文释义和个人例句；双击条目、选中后按 Enter，或点击“查看词条”打开。
- “计划复习”按上方规则安排当前收藏，不受生词本搜索筛选影响。
- “导出 CSV”导出全部当前收藏，包括单词、音标、中英释义、个人例句与收藏时间，不受搜索筛选影响，不包含已取消收藏条目或复习进度；CSV 暂不支持导回应用。

例句与学习分页
- 四个分页是“例句、派生、词根、近义词”。主词库收录的相关词可点击继续查询。
- 默认最多显示 3 组“推荐双语例句”：句中实际出现查询词或来源明确记录词形，并符合短句与标点条件。在都符合筛选条件且词形匹配程度相同时，已有学习卡优先，其次原创练习、社区语料，同类再优先较短的句子。可展开“筛选依据与来源说明”查看具体规则；规则只辅助阅读排序，不代表人工审校或语义准确性保证。
- 已核对的例句在原句前标出目标词在本句中的词性和中文译法；这是词巢逐句整理的学习提示，不是 Tatoeba 的原始字段。没有核对标注的例句不显示推测结果。
- 若没有符合条件的短句，会显示一条“双语语料参考”。其余例句、长句或需要上下文的条目在“更多语料”中，点击展开。
- 大小写、空白和句读标点归一后重复的英文合并展示；不同的原文、原译文、作者、编号、许可和链接仍在“出处”或“出处与原译文”中。来源地址可选中复制，不会自动打开浏览器。
- 原创例句标明“非考试真题”，社区译文保留简繁体。筛选不会生成新例句、改写译文或自动判断社区句子属于哪个词典义项。
- WordNet 英文例句按原始词典义项分组，保留英文释义和义项编号，没有配套中文译文；没有使用查询拼写的句子放在“补充英文例句”，可能使用词形变化或同义词。
- 常用搭配、词源原始记录和参考来源按需展开；各分页、各分组独立记住展开状态，切换单词后恢复默认。
- 派生、词基、复合词和复数/过去式有区别；词根说明区分历史来源、现代构词和助记。近义词不能在所有句子中互换。
- 中文释义按词性分行，浅绿色突出首条；“英文释义 ＋”默认收起，点击查看完整内容，切换单词后重新收起。

关闭、最小化和后台运行
1. 点击关闭按钮 × 或按 Alt+F4，默认询问“最小化到系统托盘”“退出程序”或“取消”。勾选“记住我的选择”后，下次会按该选择处理。
2. 顶部“设置”可分别修改关闭与最小化方式，也可把关闭方式改回“每次询问”。最小化按钮 − 默认缩到任务栏，可在设置中改为托盘。
3. 藏到托盘后，复制查词仍按开关状态运行，但不会自动弹出窗口。图标可能收在任务栏右下角的小箭头中。
4. 双击托盘词巢图标，或右键选择“显示词巢”，即可恢复窗口；再次打开 词巢.exe 也会请求唤回已运行的窗口。
5. 右键托盘图标可开关“复制查词”、进入“窗口与后台设置…”或选择“退出词巢”。“退出词巢”会完全退出，不受记住的关闭方式影响。
托盘不可用、添加图标失败或保存失败时，程序会保留或恢复窗口并提示。若提示笔记尚未保存，请先处理保存问题。

资料与边界
3,403,176 是合并去重后的主词库记录数，包括词组、变形词、专名与专业表达，不表示同样数量的基础词汇，也不表示每条都有音标、英文释义或完整中文学习卡。
其中 3,386,635 条有中文释义，353,030 条有音标，177,409 条有英文释义；字段缺失时如实显示缺项，不自动补齐。
扩充来源为 ECDICT 1.0.28 历史发行：发布页日期 2017-09-20，SQLite 附件在 2018 年上传。原有词条优先，新条目带来源标识；历史释义可能混杂或过时，不代表最新词汇全覆盖。
WordNet 覆盖 127,311 个词头；词源数据为 2023-12 快照，覆盖 134,158 个词头。
0.7.0 扩充主词库，学习分页仍沿用已有资料。原有 7,684 个优先词中，6,260 词有双语例句、5,416 词有词族/派生记录、6,887 词有词源记录、6,510 词有近义关系；4,078 词四栏都有资料，不能把这一覆盖比例套用到新增词条。
优先词中有 4,948 词带 ECDICT 的 ielts 标签，这不是雅思官方完整词表。原有 355 张完整中文学习卡保留；精确统计见 LEARNING_COVERAGE.md，逐词表见 learning-coverage.tsv。
资料之间会重叠，不能相加。自动提取的词源可能有疏漏，中文整理和例句筛选也不等于专业词典编辑逐条审定。
缺少学习资料时如实提示；本版没有联网查询、OCR、整句翻译、运行时 AI、云同步、CSV 导入或完整备份管理界面。朗读依赖本机可用英文语音，计划复习采用上述固定间隔规则。

个人数据、升级与回退
数据目录是 %LOCALAPPDATA%\WordNest，在资源管理器地址栏输入即可打开。
- favorites.tsv：当前收藏、已取消收藏的条目与个人例句。
- history.tsv：最近 50 或 100 个不同的成功查询词（默认 100 个）；不保存完整剪贴板内容。
- review.tsv：每词复习档位、下次到期时间和未完成的一轮进度。
- settings.properties：窗口、复制查词、上次显示词条，以及朗读语音和语速等设置。
- favorites.tsv.v1-backup：旧版生词本首次升级前的备份，迁移时生成；已有不同内容的同名备份时使用唯一后缀。
- dictionary-cache：从随包词库建立的可重建缓存，不含个人收藏、笔记、历史或复习进度。

主词库压缩分片约 97.4 MiB，解压后单份缓存约 346.9 MiB，这不是进程总内存。备份个人数据时可省略 dictionary-cache；如需清理，先完全退出，只删除这个缓存子目录，下次启动会重新建立。不要删除包含收藏和笔记的整个 WordNest 数据目录。

升级步骤：
1. 手动完全退出旧版。若在托盘中运行，右键旧版托盘图标选择“退出词巢”（0.7.3 及更早版本显示“退出拾词”）；仅隐藏窗口不等于退出。
2. 若旧版托盘菜单显示方框：双击托盘图标恢复主窗口 → 顶部“设置” → 将“点击关闭按钮 × 时”改为“退出程序” → “保存” → 点击窗口 × 退出。
3. 复制整个数据目录作为备份，再把新 ZIP 完整解压到新目录，启动新版。保留旧包，不向旧目录零散覆盖文件。

同一 Windows 用户下的新旧版本共用数据目录。旧实例还在运行时，再次打开 EXE 只会唤回旧窗口，不会自动切换为新版。
从 0.6.0 升级时，收藏、笔记与复习文件格式不变；词库缓存单独建立。从 0.5.0 升级时生词本仍保持 v2，复习进度另存 review.tsv。回退 0.5.0 后没有计划复习或朗读设置界面；请先退出并备份个人数据，以保留新版进度。
新版能读取旧 v1 生词本；首次保存笔记、收藏或取消收藏之前，先保留旧文件的原样备份，再写入 v2 格式。仅打开软件不会立即迁移；无法保留备份时不会升级或替换原生词本。这份迁移前备份不是持续自动备份。

回退到 0.4.x：
1. 完全退出新版，另行复制整个当前数据目录，保留升级后新增内容。
2. 找到升级前自行保存的 favorites.tsv，或这次迁移生成的 favorites.tsv.v1-backup（必要时核对唯一后缀）；复制回数据目录并命名为 favorites.tsv。
3. 再启动旧版。0.4.x 不能直接读取 v2 文件；迁移前备份不含升级后新增的收藏、笔记和状态修改，回退不会自动合并这些新内容。

CSV 只导出当前收藏，不含复习进度且不能导入，不能代替整个数据目录备份。数据保存在本机、未加密，不上传查询、收藏或朗读内容；更换程序目录不自动删除这些数据。

验证与源码
本版实际检查结果见 VALIDATION.md，包括完整词库读回、原词条保留、缓存和查询检查，具体完成项、统计与运行环境以该文件为准。旧版复习和朗读验证保留为历史记录；单次加载计时不代表所有机器的速度。
本次未操作实际桌面，未进行真实窗口、托盘、焦点、快捷键或系统 DPI 交互验收；语音可用性和声音输出的具体验证也以 VALIDATION.md 为准，控件显示不等于已听音验收。
源码版需 JDK 17+：先运行 scripts\build.ps1，再用 Launch.cmd 启动；源码或资源更新后要重新构建。
学习资料可用 python scripts\prepare_open_learning.py --check 离线核对。

0.7.5 的 GitHub Release 使用新图标与“词巢”名称；原 GitHub 仓库与个人数据目录仍叫 WordNest。标题栏与正文保持浅绿白与深绿色，不改变 Windows 主题；请保留 app/lib 中的界面依赖文件。

查词历史容量设置：在“历史”窗口选择最多保留 50 条或 100 条（默认 100 条）。按最近查询顺序去重，超出上限立即淘汰最早的记录；从 100 改为 50 会立即保留最新 50 条，再调大不会恢复已清理的记录。清空历史不重置容量设置。前进/后退路径独立保留到本次程序退出，收藏、笔记和复习进度不受影响。50 条设置使用新版历史文件头；旧版本无法读取时会保留文件并使用临时历史，回退前可先切回 100 条。

0.7.3 托盘菜单：托盘右键菜单使用与主界面相同的 Swing 中文绘制方式；支持方向键选择、Enter 执行、Esc 或点击其他窗口关闭。更新后须从旧托盘菜单退出程序，再重新打开桌面快捷方式；旧版本运行时再次启动只会唤回旧窗口。设置窗口可以调整大小，底部按钮固定显示，正文在空间不足时滚动。

0.7.4 更名说明：窗口、托盘、桌面快捷方式及可执行文件改称“词巢”；图标采用橙底绿色巢形与 A 字母卡。为了让收藏、历史、笔记和复习进度自动延续，个人数据目录仍为 %LOCALAPPDATA%\WordNest，不要手动改名。
