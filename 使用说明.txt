拾词 WordNest 0.5.0 · Windows 64 位便携版

启动
1. 完整解压 WordNest-0.5.0-Windows-x64.zip，打开其中的 WordNest 文件夹。
2. 双击 WordNest.exe；无需安装 Java、配置 API 或联网。
3. 等待资料加载完成，输入英文单词并按 Enter；Ctrl+L 可聚焦搜索框。
请保留整个文件夹，app、runtime、文档和许可证需要一起保留，不能只取出 EXE。

本次更新
- 新增本机查词历史和前进、后退；最近列表最多保留 100 个不同的成功查询词。
- 取消收藏后保留个人例句，可立即撤销，或从生词本的“最近取消收藏”中恢复。
- 例句按查询词、来源记录词形、长度和标点筛选排序；重复英文合并展示，原文、原译文和出处仍保留。WordNet 英文例句按真实词典义项分组。
- 沿用现有词库、离线运行方式和 0.4.3 的托盘中文字体修复，没有加入自动翻译或 AI。
- 旧生词本首次写入会升级为 v2 格式。0.4.x 不能直接读取升级后的文件，请先阅读“个人数据、升级与回退”。

查词与历史
- 顶部可切换“置顶”和“复制查词”。复制查词只接受英文字母组成的单词；中文、句子、图片、数字、连字符和撇号等不会替换当前词。含连字符、撇号或空格的词，可在搜索框手动查询词库收录内容。
- 点击“← 后退”“前进 →”，或在应用窗口内按 Alt+← / Alt+→，回看本次打开程序后的查词路径。
- 点“历史”，选中词条后点“查看词条”重新打开。最近列表按新查询排序，忽略大小写去重；重查已有词会移到最前，未找到的词不记录。
- 启动显示上次词条不计为新查询；前进后退不改变最近列表顺序。回退后查询另一个词会结束原来的前进路径，连续查当前词不增加重复导航步骤。
- “历史 → 清空历史”确认后清除最近列表和本次前进后退路径；当前词条、收藏和个人例句保留。
- 历史文件损坏或无法读取时，原文件保留，本次历史改为只在内存中保存，查词和生词本仍可使用。若运行中历史写入失败，会提示未能保存，但本次仍可前进后退。

收藏、个人例句与复习
- 点“收藏”加入生词本。再次点“已收藏”只取消收藏，个人例句仍在本机；窗口底部“撤销取消收藏”可恢复刚取消的一项。
- 打开“生词本 → 最近取消收藏”，选中条目后可点“恢复收藏”，也可点“查看词条”继续编辑笔记。重启后仍能从这里找到保留条目。
- “我的例句”停止输入约 750 毫秒后保存。第一次填写非空笔记会自动收藏；已取消收藏的词继续编辑只保存笔记，不会自动重新收藏。
- 切换学习分页保留编辑内容。个人例句最多 20,000 字符；切词或退出前会尝试保存，失败时保留当前内容并提示，请先处理保存问题。
- 生词本可搜索当前收藏的单词、中文释义和个人例句；双击条目、选中后按 Enter，或点击“查看词条”打开。
- “翻卡复习”随机排列全部当前收藏，先看单词和个人例句，点“显示释义”看中文，再点“下一张”。最后一张后循环，没有间隔复习调度。
- “导出 CSV”导出全部当前收藏，包括单词、音标、中英释义、个人例句与收藏时间。复习和导出不受搜索筛选影响，也不包含已取消收藏的条目；CSV 暂不支持导回应用。

例句与学习分页
- 四个分页是“例句、派生、词根、近义词”。主词库收录的相关词可点击继续查询。
- 默认最多显示 3 组“推荐双语例句”：句中实际出现查询词或来源明确记录词形，并符合短句与标点条件。在都符合筛选条件且词形匹配程度相同时，已有学习卡优先，其次原创练习、社区语料，同类再优先较短的句子。可展开“筛选依据与来源说明”查看具体规则；规则只辅助阅读排序，不代表人工审校或语义准确性保证。
- 若没有符合条件的短句，会显示一条“双语语料参考”。其余例句、长句或需要上下文的条目在“更多语料”中，点击展开。
- 大小写、空白和句读标点归一后重复的英文合并展示；不同的原文、原译文、作者、编号、许可和链接仍在“出处”或“出处与原译文”中。来源地址可选中复制，不会自动打开浏览器。
- 原创例句标明“非考试真题”，社区译文保留简繁体。筛选不会生成新例句、改写译文或自动判断社区句子属于哪个词典义项。
- WordNet 英文例句按原始词典义项分组，保留英文释义和义项编号，没有配套中文译文；没有使用查询拼写的句子放在“补充英文例句”，可能使用词形变化或同义词。
- 常用搭配、词源原始记录和参考来源按需展开；各分页、各分组独立记住展开状态，切换单词后恢复默认。
- 派生、词基、复合词和复数/过去式有区别；词根说明区分历史来源、现代构词和助记。近义词不能在所有句子中互换。
- 中文释义按词性分行，浅绿色突出首条；“英文释义 ＋”默认收起，点击查看完整内容，切换单词后重新收起。

关闭、最小化和后台运行
1. 点击关闭按钮 × 或按 Alt+F4，默认询问“最小化到系统托盘”“退出程序”或“取消”。勾选“记住我的选择”后，下次会按该选择处理。
2. 顶部“设置”可分别修改关闭与最小化方式，也可把关闭方式改回“每次询问”。最小化按钮 − 默认缩到任务栏，可在设置中改为托盘。
3. 藏到托盘后，复制查词仍按开关状态运行，但不会自动弹出窗口。图标可能收在任务栏右下角的小箭头中。
4. 双击托盘拾词图标，或右键选择“显示拾词”，即可恢复窗口；再次打开 WordNest.exe 也会请求唤回已运行的窗口。
5. 右键托盘图标可开关“复制查词”、进入“窗口与后台设置…”或选择“退出拾词”。“退出拾词”会完全退出，不受记住的关闭方式影响。
托盘不可用、添加图标失败或保存失败时，程序会保留或恢复窗口并提示。若提示笔记尚未保存，请先处理保存问题。

资料与边界
770,611 是主词库记录数，不表示每个词都有完整中文学习卡。
WordNet 覆盖 127,311 个词头；词源数据为 2023-12 快照，覆盖 134,158 个词头。
0.5.0 沿用已有学习资料，未扩充词库。7,684 个优先词中，6,260 词有双语例句、5,416 词有词族/派生记录、6,887 词有词源记录、6,510 词有近义关系；4,078 词四栏都有资料。
优先词中有 4,948 词带 ECDICT 的 ielts 标签，这不是雅思官方完整词表。原有 355 张完整中文学习卡保留；精确统计见 LEARNING_COVERAGE.md，逐词表见 learning-coverage.tsv。
资料之间会重叠，不能相加。自动提取的词源可能有疏漏，中文整理和例句筛选也不等于专业词典编辑逐条审定。
缺少学习资料时如实提示；本版没有联网查询、发音、OCR、整句翻译、运行时 AI、云同步、CSV 导入、间隔复习算法或完整备份管理界面。

个人数据、升级与回退
数据目录是 %LOCALAPPDATA%\WordNest，在资源管理器地址栏输入即可打开。
- favorites.tsv：当前收藏、已取消收藏的条目与个人例句。
- history.tsv：最近 100 个不同的成功查询词；不保存完整剪贴板内容。
- settings.properties：窗口、复制查词和上次显示词条等设置。
- favorites.tsv.v1-backup：旧版生词本首次升级前的备份，迁移时生成；已有不同内容的同名备份时使用唯一后缀。

升级步骤：
1. 完全退出旧版。若在托盘中运行，右键拾词图标选择“退出拾词”；仅隐藏窗口不等于退出。
2. 若旧版托盘菜单显示方框：双击托盘图标恢复主窗口 → 顶部“设置” → 将“点击关闭按钮 × 时”改为“退出程序” → “保存” → 点击窗口 × 退出。
3. 复制整个数据目录作为备份，再把新 ZIP 完整解压到新目录，启动新版。保留旧包，不向旧目录零散覆盖文件。

同一 Windows 用户下的新旧版本共用数据目录。旧实例还在运行时，再次打开 EXE 只会唤回旧窗口，不会自动切换为新版。
新版能读取旧 v1 生词本；首次保存笔记、收藏或取消收藏之前，先保留旧文件的原样备份，再写入 v2 格式。仅打开软件不会立即迁移；无法保留备份时不会升级或替换原生词本。这份迁移前备份不是持续自动备份。

回退到 0.4.x：
1. 完全退出 0.5.0，另行复制整个当前数据目录，保留升级后新增内容。
2. 找到升级前自行保存的 favorites.tsv，或这次迁移生成的 favorites.tsv.v1-backup（必要时核对唯一后缀）；复制回数据目录并命名为 favorites.tsv。
3. 再启动旧版。0.4.x 不能直接读取 v2 文件；迁移前备份不含升级后新增的收藏、笔记和状态修改，回退不会自动合并这些新内容。

CSV 只导出当前收藏且不能导入，不能代替整个数据目录备份。数据保存在本机、未加密，不上传查询或收藏；更换程序目录不自动删除这些数据。
